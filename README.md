# Rambabu Dhanavath — Portfolio Website

> A personal portfolio website showcasing my skills, projects, and experience as a Software Engineer.

**Live site:** https://rambabudhanavath.github.io/PortFolio/

## Overview

This is a responsive, single-page portfolio site featuring:

- 🏠 **Hero section** — introduction and quick links
- 👨‍💻 **About** — background, skills, and experience
- 🛠️ **Skills** — tech stack highlights
- 📁 **Projects** — selected work and academic projects
- 📬 **Contact** — ways to get in touch

## Tech Stack

- **HTML5** — semantic markup
- **CSS3 / SCSS** — custom styling with Sass preprocessing
- **JavaScript** — interactivity and animations
- **Libraries** — jQuery, Bootstrap (see `lib/`)

## Project Structure

```
PortFolio/
├── index.html        # Main page
├── css/              # Compiled stylesheets
├── scss/             # Sass source files
├── js/               # JavaScript
├── lib/              # Third-party libraries
├── images/           # Images and media
└── fonts/            # Web fonts
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/RambabuDhanavath/PortFolio.git
   cd PortFolio
   ```

2. Open `index.html` in your browser, or serve it locally:

   ```bash
   npx serve .
   ```

3. (Optional) To work with the Sass sources, install [Prepros](https://prepros.io/) — a `prepros-6.config` is included.

## Deployment

This site is deployed with **GitHub Pages** — any push to `main` updates the live site automatically.
